# SAMAZ Mobile Technology React Website

## Run locally

```bash
npm install
npm run dev
```

## Build for hosting

```bash
npm run build
```

Upload everything inside the generated `dist` folder to your hosting `public_html` folder.

## Main files
- `src/App.jsx` - page content and React components
- `src/styles.css` - blue and white website design
- `src/main.jsx` - React entry
- `index.html` - base HTML
